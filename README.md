# pl0-parser

PL/0風言語の再帰下降パーサ（C言語実装）

## 概要

このパーサは、PL/0風の簡易プログラミング言語を解析し、
アセンブリコードを生成する再帰下降型コンパイラの構文解析部分です。
名古屋工業大学 情報工学科の演習課題として作成しました。

## 対応構文

| 構文 | 説明 |
|------|------|
| `program <name>;` | プログラム宣言 |
| `begin ... end` | 複合文ブロック |
| `var <id>, ...;` | 変数宣言 |
| `<id> := <expr>` | 代入文 |
| `+`, `-`, `*`, `div` | 四則演算 |
| `=`, `<>`, `<`, `>`, `<=`, `>=` | 比較演算子 |
| `if <cond>` | 条件文 |

## ファイル構成

```
pl0-parser/
├── parse.c      # 構文解析器（本体）
├── getsym.h     # 字句解析器ヘッダ（別途必要）
├── getsym.c     # 字句解析器実装（別途必要）
└── README.md    # このファイル
```

## ビルド方法

```bash
gcc parse.c getsym.c -o parser -I.
```

## 使用方法

```bash
./parser input.pl0 output.asm
```

## 生成されるアセンブリ命令（抜粋）

| 命令 | 説明 |
|------|------|
| `loadi r0, N` | レジスタr0に即値Nをロード |
| `addi r0, N` | r0にNを加算 |
| `subi r0, N` | r0からNを減算 |
| `muli r0, N` | r0にNを乗算 |
| `writed r0` | r0の値を10進数で出力 |
| `halt` | プログラム終了 |

## 既知の制限事項

- 式の左辺は数値またはIDENTIFIERのみ対応
- ネストした式（括弧）は未対応
- 変数テーブルは最大32エントリ
